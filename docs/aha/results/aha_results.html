What it says

Geometric failures are easy; subtle & semantic ones are hard.

When the arm goes to the wrong place (translation) the state trajectory visibly deviates → AUC ~1.0. A grasp that moves correctly but fails to grip (0.58), or a wrong-order sequence (0.67), barely register — exactly the failure surface a state+vision detector should miss, and a clean map of where tactile/force signals would earn their keep.

SMD and RND are complementary — keep the cascade.

Across modes neither detector dominates (state 0.70, vision 0.78). On our earlier SO-101 task RND carried everything and SMD was chance; here state pulls its weight on kinematic modes. No single signal covers both worlds.

The honest negative: cross-task AUC of 0.29 is a feature-correct result, not a bug. SMD/RND are per-deployment anomaly detectors — a different task looks anomalous wholesale, so the success/failure ordering inverts. The productization lesson is that calibration belongs to each deployment, not a single global model.

Read before quoting

  • AUC is the honest metric. The false-alarm rate reads 1.0 in both splits — a small-sample threshold artifact (a 90th-percentile bound set from ~11–13 successes, tested on 6–8). AUC is threshold-independent; the false alarm goes away with more success demos.
  • Small n per mode (5–6). stack_blocks contributed successes only — generation was time-capped at ~2h and it's the slow task.
  • Depth-first slice: 2 deep tasks + 1 partial. Broad cross-task claims need more tasks.

Method & proof

Policy-free by design. AHA trajectories come from scripted planners with injected perturbations, so we score the labeled trajectories directly — no VLA in the loop. SMD = one Gaussian over a fixed 17-D proprioceptive state (Mahalanobis distance); RND = random-network distillation on a standalone SigLIP embedding of the front + wrist cameras; ACE dropped (needs a live policy). A real train/eval split fits detectors + threshold on train successes and scores held-out successes + all failures.

The canonical stack — CoppeliaSim 4.1 → PyRep → RLBench (peract + AHA overlay) → FailGen — was stood up on a rented V100 and generated all 48 labeled trajectories end-to-end. Pipeline: gen_aha.py → ingest_aha.py → eval_aha.py. Reports, install log, and generation transcripts saved as artifacts.
